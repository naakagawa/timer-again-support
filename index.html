Timer Againの使い方

タイマーの時間と回数を設定し、「開始」をタップします。アラームが鳴ったら、準備ができたタイミングで「繰り返す」をタップして次の回を始められます。

よくある質問

iPhoneやiPadでアラームが鳴りません

「設定」からTimer Againのアラームを許可してください。音を鳴らしたい場合は、アプリ内のサウンド設定で音のある項目を選んでください。

コントロールセンターからタイマーを開始するには？

アプリで一度タイマーを開始してから、コントロールセンターの編集画面でTimer Againの「前回のタイマーを開始」を追加します。

7回以上の設定や購入の復元はどうすればいいですか？

無料では6回まで設定できます。「7回以上をアンロック」を一度購入すると、最大99回まで設定できます。購入済みの場合は、購入時と同じApple Accountで、アプリのアンロック画面にある「購入を復元」をタップしてください。

Using Timer Again

Set the duration and number of rounds, then tap Start. When the alarm goes off, tap Repeat whenever you’re ready to begin the next round.

Frequently asked questions

Why can’t I hear the alarm on my iPhone or iPad?

Open Settings and allow alarms for Timer Again. In the app, check that Sound is set to an audible option.

How do I start a timer from Control Center?

Start a timer in the app once, then edit Control Center and add Timer Again’s Start Last Timer control.

How do I unlock more rounds or restore my purchase?

You can set up to six rounds for free. A one-time purchase unlocks up to 99 rounds. To restore a previous purchase, use the same Apple Account and tap Restore Purchases on the unlock screen.
